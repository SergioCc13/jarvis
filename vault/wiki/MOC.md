# Jarvis — Map of content

Wiki for the **[SergioCc13/jarvis](https://github.com/SergioCc13/jarvis)** project: a voice
assistant on Claude Code + voicemode, with a HUD, a Telegram/phone voice bridge and an agent
on every device, all over Tailscale and running on a Raspberry Pi.
